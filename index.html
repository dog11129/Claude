📲 Kuschelinsel als App

Auf dem iPhone/iPad geht das über Safari – dann läuft das Spiel ohne Adressleiste im Vollbild:

  1. Unten auf Teilen ⬆︎ tippen
  2. „Zum Home-Bildschirm“ wählen
  3. Kuschelinsel über das neue Symbol starten – ohne Adressleiste, ganz im Vollbild

Die Home-Bildschirm-App hat einen eigenen Speicher. Deine Insel nimmst du so mit: in Safari unter „Meine Inseln“ auf 💾 tippen, dann in der App „📂 Insel aus Datei laden“.
